# Architecture Decision Records

Use this directory for decisions that should outlive a single pull request or chat session.

Create ADRs as small Markdown files named with a zero-padded number and a short kebab-case title:

```text
0001-use-hono-for-api.md
0002-add-recipe-storage.md
```

Recommended structure:

```markdown
# 0001. Decision Title

Date: YYYY-MM-DD

## Status

Proposed | Accepted | Superseded

## Context

What problem or constraint led to this decision?

## Decision

What are we choosing?

## Consequences

What tradeoffs, follow-up work, or constraints does this create?
```
